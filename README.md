## 快速运行

```bash
python -m pip install waac_genesiscope-0.1.0-py3-none-any.whl
waac-genesiscope verify
waac-genesiscope summary
waac-genesiscope serve --host 127.0.0.1 --port 8771
```

浏览器打开 `http://127.0.0.1:8771`。

无需安装时，解压 `WAAC_GENESISCOPE_Studio_Offline.zip`，直接打开 `index.html`。
